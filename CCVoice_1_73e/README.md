# **OpenCCVoice Guidance Controller**

取扱説明書 / コマンドリファレンス  
**バージョン: v1.73e-Unified-Safe**  
**最終更新日: 2026/02/13**  
対象ハード: Arduino Nano (ATmega328P / 5V)  
通信設定: 115200 bps / 8N1 / 改行なし(またはLF)

---

## ■ 概要

本機は DMR無線機のID送出を自動制御するコントローラです。  
PCとUSB接続し、シリアルモニタから各種コマンドで設定を変更できます。

全ての設定は EEPROM に自動保存され、電源断でも保持されます。  
**v1.73c から EEPROM にバージョン管理機能を搭載**し、スケッチ更新時の設定破損を防ぐ仕様になりました。  
**v1.73d では「周期IDの静寂ガード」機能（k####）** が追加され、通話中の割り込み問題を大幅に改善しました。  
**v1.73e では「送信直後ガード（postTxIgnore）」と「周期ID catch-up 対策」** により、実運用上の誤発火・連続発火を根治しました。

---

## ■ 本バージョン（v1.73e）の特徴

### 【v1.73e 新機能・修正点】

**送信直後ガード（postTxIgnore）**

- PTT OFF 直後、A0 残留BUSY・スケルチテール・瞬間的な BUSY 揺れによる
  **短発ID（001）や周期IDの誤発火を防止**
- BUSY が連続して `idleMin` ms 以上 OFF になった時点で自動解除
- `isSuppressedNow()` に統合されており、短発・周期ID の両方に適用

**周期ID catch-up 対策**

- 長時間 BUSY/抑止が続いた後の **周期ID 連続送信を防止**
- `nextPeriodicAt` を `while` で未来へ追い付かせ、`periodicDue` は最大1回のみ立てる設計

**A0 BUSY 観測の安定化**

- 抑止中であっても A0 の BUSY 状態（`a0Busy`）は継続して観測
- 抑止中は AUTO 判定用カウント（`a0_event_count`）のみ増加させない

### 【v1.73d から継承：周期ID 静寂ガード（Quiet Guard）】

- 周期ID（002/003）は、**BUSY が OFF になってから k#### ms 静寂継続**した場合のみ送出
- BUSY中 / 静寂不足 / 抑止期間中は **延期（periodicDue保持）**
- 新コマンド：`k####`（既定：2000ms、`k0` で無効）
- `q` で `QUIET(ms)=xxxx` を確認可能

### 【EEPROM バージョン管理（v1.73c〜、config.ver=4）】

- 起動時に EEPROM のレイアウト版を判定
- 古いバージョンを自動補完 / 移行（マイグレーション）
- `q` に **EEPROM_VER=4** と表示

> **注意**：`k0` を設定して再起動すると、`migrateOrInit()` の補完ロジックにより
> `periodQuietMs` が 2000ms にリセットされる場合があります。
> 再起動後は `q` で QUIET(ms) を確認し、必要なら再度 `k0` を実行してください。

## 2. コマンド詳細解説

**[m：モード設定]**  
m0 … D6（デジタルBUSY）  
m1 … A0（アナログ）  
m2 … AUTO（D6/A0 を観測し優位側へ自動固定）  
※ AUTO中は D6/A0 どちらの入力でも ID が出る

**[b：最大受信長]**  
b3900（3.9秒）までを短発として受付  
dur ≥ b#### は長話と判定し 10秒抑止（LONG_SUP）

**[n / i：最小受信長 / 直前アイドル]**  
n#### … dur < n#### はノイズ扱い  
i#### … 直前アイドル < i#### は短発無効化

**[s / t / r：抑止ガード]**  
s1 … 抑止 ON（長話/バースト検出）  
t1 … 自局送出後、r#### ms BUSY を無視  
r#### … 送信後無視時間

**[p：周期ID]**  
p##（分）で 002/003 を交互送出  
絶対時刻基準で等間隔

**[k：周期IDの静寂ガード（v1.73d〜）]**  
周期IDを出すための「BUSY OFF からの静寂期間（ms）」

- 例：k2000 → BUSY 終了後 2秒静かなら送出
- 例：k5000 → より強い割り込み防止
- k0 → 静寂ガード無効（※再起動後にリセットされる場合あり、要確認）

**[w：AUTO観測期間]**  
AUTO_WINDOW 分観測 → 優位側へ固定（D13 高速点滅）

**[A0検知（L/G/a）]**  
LOW/HIGH閾値＋保持時間でアナログBUSYを安定化

**[d：DFPフェイルセーフ]**  
DFPlayer BUSY が戻らない場合、d#### ms 経過で強制 PTT OFF  
d0 で無効化

**[g：TM BUSY極性]**  
g0 = LOW=busy  
g1 = HIGH=busy（既定）

**[x / r：停止と再開]**  
x … 全動作停止  
r … 停止中の復帰

**[F：初期値へ]**  
全設定を初期化し EEPROM 保存

**[h / 0〜3：ヘルプ・ログ]**  
h … コマンド一覧  
0〜3 … ログレベル（NONE/ERR/INF/DBG）

## 3. LED表示の意味

[D4]  … D6 BUSY受信時点灯（AUTO中はD12と交互点滅）  
[D12] … A0 検知時点灯（AUTO中はD4と交互点滅）  
[D13] … 抑止/短発窓/AUTO固定（高速点滅）表示  
[D2]  … DFPlayer BUSYミラー（反転：再生中=HIGH）

## 4. フェイルセーフ（DFPlayer BUSY異常）

DFPlayer BUSY が戻らない場合、**d#### ms 経過後に強制 PTT OFF**。

- 既定：d20000
- d0：無効（判定スキップ）

## 5. トラブルシューティング

**● IDが出ない**

- 停止中（x）→ r
- 長話（b3900超）→ 抑止
- D13 点灯中（抑止）では動作しない
- 送信直後の postTxIgnore ガード中（BUSY が落ち着くまで自動解除待ち）

**● ID が止まらない**

- t1 と r#### を増やす
- n#### / i#### を大きくする

**● 送信後に ID が誤発火する**

- v1.73e の postTxIgnore ガードが有効か確認（ログレベル 3 で `[POST-TX] cleared` を確認）
- BUSY が落ち着かない環境では i#### を大きくする

**● 周期IDが連続して送出された**

- v1.73e の catch-up 対策が有効か確認
- 長時間の BUSY 後にまとめて送出される旧挙動は本バージョンで修正済み

**● 音声が途中で切れる**

- d#### を延長（d20000 など）
- SDカード階層（/mp3/0001.mp3）を確認
- D7(BUSY) が途中 HIGH になっていないか

**● BUSY判定が逆**

- g0/g1 の設定確認
- D6 は INPUT_PULLUP 必須

**● k0 を設定したのに再起動後に k2000 に戻る**

- 既知の挙動。再起動後に `q` で確認し、必要なら再度 `k0` を実行

## 6. 配線メモ（v1.73e）

```
DFPlayer TX → D10（Arduino RX）
DFPlayer RX ← D11（Arduino TX）
DFPlayer BUSY（LOW=再生中）→ D7
D7ミラー（反転）→ D2
TM BUSY → D6（g0/g1 で極性指定）
PTT → D5（HIGH=送信）
LED → D4（D6） / D12（A0） / D13（抑止/AUTO）
テストSW → D3（INPUT_PULLUP）
```

## 7. v1.73e 仕様まとめ

**【送信直後ガード（postTxIgnore）】**

- PTT OFF 直後に `postTxIgnore = true` をセット
- BUSY が `idleMin` ms 連続 OFF になるまで、短発・周期ID を抑止扱いにする
- `isSuppressedNow()` に組み込まれており、既存の抑止ロジックと統一

**【周期ID catch-up 対策】**

- `nextPeriodicAt` の更新を `while` ループで実施
- 長時間延期後も `periodicDue` は最大1回のみ
- ログレベル DBG（3）で `[Periodic] due flag set (catch-up)` を確認可能

**【EEPROM バージョン（CONFIG_VERSION=4）】**

- v1.73e は EEPROM レイアウト変更なし（v1.73d と同一）
- v1.73d（ver=4）からの更新では自動移行不要、EEPROM をそのまま継続利用可能
- v1.73c 以前からの更新時は自動マイグレーションが実行される
