## v2.10 → v2.20 アップグレード

--------------------------------------------------------------------

### 1. 変更内容の概要

v2.20 は **AT24C32 外部EEPROMへの二重保存対応**が主な変更です。
ピンマップ・コマンド体系に**破壊的変更はありません**。

| 項目 | v2.10 | v2.20 |
|------|-------|-------|
| 設定保存先 | 内蔵EEPROMのみ | AT24C32 + 内蔵EEPROM（両方） |
| 起動時読み込み | 内蔵EEPROM | AT24C32 優先（未接続時は内蔵） |
| タイムスタンプ | なし | DS3231時刻で新旧判定 |
| EEPROM ver | 5 | 6 |
| 新コマンド | — | なし（変更なし） |
| ピンマップ | Ver.5 | Ver.5（変更なし） |

--------------------------------------------------------------------

### 2. EEPROM の互換性

v2.20 の EEPROM レイアウトは v2.10（ver=5）から **`saveTimestamp` フィールドを追加**しています（ver=6）。

- **旧設定はそのまま引き継がれます。**
- スケッチ書き込み後に `F`（初期化）は不要です。
- `q` で `EEPROM_VER=6` と表示されれば移行完了です。

--------------------------------------------------------------------

### 3. 書き込み直後の確認手順

```
1. v2.20 を書き込む
2. シリアルモニタ（115200bps）を開く
3. 起動ログを確認：
   [RTC] DS3231 found.
   [EEPROM] AT24C32 found. Using external EEPROM.  ← AT24C32接続時
   [EEPROM] Settings Loaded.
   [START] OpenCCVoice v2.20 ...
4. q を入力して設定を確認：
   EEPROM_VER=6 が表示されれば完了
```

--------------------------------------------------------------------

### 4. 不一致警告が出た場合

```
[EEPROM] WARNING: AT24C32 and internal EEPROM mismatch.
[EEPROM] Using AT24C32. Re-save settings to sync.
```

AT24C32 未接続中に設定変更した場合に表示されます。
AT24C32 の設定で起動しています。現在の設定を確認して問題なければ
任意のコマンド（例：`p30`）を再入力するだけで両方に同期保存されます。

## v2.01 → v2.10 アップグレード

--------------------------------------------------------------------

### 1. 変更内容の概要

v2.10 は **DS3231 RTC モジュールへの対応**が主な変更です。  
ピンマップ・コマンド体系に**破壊的変更はありません**。

| 項目 | v2.01 | v2.10 |
|------|-------|-------|
| 周期ID基準 | millis() 相対 | RTC 正時アライン（DS3231接続時） |
| EEPROM ver | 4 | 5 |
| 新コマンド | — | `T`（時刻設定）、`u0/u1`（アライン切替） |
| ピンマップ | Ver.5 | Ver.5（変更なし） |
| I²C | 未使用 | A4(SDA) / A5(SCL) — DS3231用 |

--------------------------------------------------------------------

### 2. EEPROM の互換性

v2.10 の EEPROM レイアウトは v2.01（ver=4）から **`rtcAlignOn` フィールドを追加**しています（ver=5）。

- **旧設定はそのまま引き継がれます。**
- スケッチ書き込み後に `F`（初期化）は不要です。
- 起動ログに `[EEPROM] Settings Loaded.` が出れば正常です。
- `q` で `EEPROM_VER=5` と表示されれば移行完了です。

--------------------------------------------------------------------

### 3. DS3231 モジュールの接続

J5 コネクタ（基板右端）に接続します。

| DS3231 モジュール | J5 ピン | Arduino |
|-------------------|---------|---------|
| SLC (SCL) | 1 | A5 |
| SDA | 2 | A4 |
| VCC | 3 | +5V |
| GND | 4 | GND |

> DS3231 を接続しない場合は、従来の millis() 相対動作のまま使用できます。

--------------------------------------------------------------------

### 4. 書き込み直後の確認手順

```
1. v2.10 を書き込む
2. シリアルモニタ（115200bps）を開く
3. 起動ログを確認：
   [RTC] DS3231 found.          ← DS3231 接続確認
   [EEPROM] Settings Loaded.    ← 既存設定を引き継ぎ
   [START] OpenCCVoice v2.10 ...
4. q を入力して設定を確認：
   [RTC] N/A(no RTC)  Align=OFF(millis)   ← DS3231未設定時
   [RTC] 2000/01/01 00:00:00  Align=ON(RTC) ← DS3231あり・時刻未設定時
5. T コマンドで現在時刻を設定：
   T20260311143000
6. q で再確認：
   [RTC] 2026/03/11 14:30:xx  Align=ON(RTC)
```

### 5. よくある質問（FAQ）

#### Q1. v2.01 から更新して F（初期化）は必要？
→ **不要。** 自動マイグレーションで旧設定を引き継ぎます。

#### Q2. DS3231 を接続しなくても動く？
→ **動きます。** 未接続時は millis() 相対動作（v2.01 と同じ）にフォールバックします。

#### Q3. p15 にしたのに正時アラインにならない
→ `q` で `Align=ON(RTC)` が出ているか確認してください。  
　`Align=OFF(millis)` の場合は DS3231 が認識されていません（配線・接続を確認）。  
　または `u0` になっていないか確認してください（`u1` で有効化）。

#### Q4. 電源を切ると時刻がリセットされる
→ DS3231 モジュールのコイン電池（CR2032）が切れています。電池を交換後、`T` コマンドで時刻を再設定してください。

#### Q5. p7 など 60 の約数でない周期を設定したら？
→ millis() 相対動作になります（v2.01 互換）。`q` で `Align=OFF(millis)` と表示されます。

#### Q6. AT24C32（モジュール上の外部EEPROM）は使う？
→ v2.10 では未使用です。同じ I²C バスに接続されていますが動作に影響はありません。
