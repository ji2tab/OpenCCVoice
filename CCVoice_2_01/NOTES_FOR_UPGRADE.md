# OpenCCVoice Guidance Controller
# アップグレード注意点（v1.73e → v2.01）
# 最終更新日: 2026-03-10

本書は、OpenCCVoice を **v2.01（Ver.5 ピンマップ対応版）** にアップグレードする際の  
重要な注意点・確認手順をまとめた技術者向けドキュメントです。  
特に **v1.73e / v1.73d / v1.73c 系** からの更新時にご確認ください。

--------------------------------------------------------------------

## 1. 重要：v2.01 は「基板 Ver.5」専用スケッチです

v2.01 は **Ver.5 基板向けにピンアサインを変更**しています。  
**旧基板（v1.73e 用配線）に v2.01 を書き込むと誤動作します。**  
必ず基板のバージョンを確認してから書き込んでください。

### ● v1.73e → v2.01 ピン変更一覧

| 信号 | v1.73e | v2.01 (Ver.5) | 備考 |
|------|--------|---------------|------|
| DFP BUSYミラー出力 | D2 | D3 | 反転出力（再生中=HIGH） |
| テストSW | D3 | D2 | INPUT_PULLUP |
| TM BUSY入力 | D6 | D11 | g0/g1 極性切替可 |
| DFPlayer BUSY入力 | D7 | D10 | LOW=再生中 |
| 抑止 LED | D13 | D6 | |
| A0検知 LED | D12 | D7 | |
| Arduino RX ← DFPlayer TX | D10 | D13 | SoftwareSerial |
| Arduino TX → DFPlayer RX | D11 | D12 | SoftwareSerial |

> **PTT（D5）、ModBusy LED（D4）、A0（A0）は変更なし。**

--------------------------------------------------------------------

## 2. EEPROM の互換性

v2.01 の EEPROM レイアウトは **v1.73d/e と同一（`config.ver = 4`）** です。  
ピン変更・コマンド変更のみで、EEPROM 構造に変更はありません。

- **旧設定はそのまま引き継がれます。**
- スケッチ書き込み後に `F`（初期化）は不要です。
- 起動ログに `[EEPROM] Settings Loaded.` が出れば正常です。

> ただし、クリーンな状態で運用を始めたい場合は `F` を推奨します。

--------------------------------------------------------------------

## 3. コマンドの変更点（v1.73e → v2.01）

### ● RESUME コマンドが `r` → `R`（大文字）に変更

| | v1.73e | v2.01 |
|---|--------|-------|
| STOP 復帰 | `r` | `R` |
| 送信後抑止時間設定 | `r####` | `r####`（変更なし） |

v1.73e では `r` が RESUME と `r####`（送信後抑止時間）の両方に使われており、  
コマンド衝突が起きる可能性がありました。  
v2.01 では RESUME を **大文字 `R`** に統一し、衝突を解消しています。

> **注意：STOP 中に `r` を入力しても復帰しません。`R`（大文字）を入力してください。**

### ● その他コマンドは変更なし
`m / n / b / i / s / t / p / k / r / L / G / a / w / d / g / q / H / x / F / 0〜3 / h`  
はすべて従来通り動作します。

## 4. 書き込み直後の正常な挙動

### ● 起動時に出る想定ログ（v1.73e からの更新時）

```
[EEPROM] Settings Loaded.
[START] OpenCCVoice v2.01 Unified/Safe (Ver.5 pinmap, R-RESUME)
[CFG] EEPROM_VER=4 SRC=DIGITAL(LOCK) MIN=500 MAX=3900 ...
```

`Version mismatch` は出ません（レイアウト変更なしのため）。

### ● 起動後に必ず実行すべき確認

`q` を入力：

```
[CFG] EEPROM_VER=4 SRC=DIGITAL(LOCK) MIN=500 MAX=3900 PER(min)=30
      TXSUP=3000 A0[L/H]=300/700 HOLD=800 AUTO(min)=30
      DFP_TIMEOUT(ms)=20000 TM_BUSY_POL=HIGH=busy QUIET(ms)=2000
```

### ● チェックポイント
- `EEPROM_VER=4`（正常ロード済み）
- `TM_BUSY_POL` が無線機仕様に一致（g0/g1）
- `DFP_TIMEOUT(ms)=20000`
- `QUIET(ms)=2000`（または設定値）
- 旧設定値（MIN / MAX / PER / TXSUP など）が保持されていること

## 5. 実機での動作確認手順

```
1. Ver.5 基板に v2.01 を書き込む
2. 起動ログを確認（Settings Loaded が出ること）
3. q を実行し、設定値を確認
4. TM BUSY 極性を実機で確認（g0/g1）
5. テストSW（D2）1クリック → Track 1 再生確認
6. 短発ID（001）が正常に動くか確認
7. 周期IDが通話中に割り込まないことを確認
8. STOP（x）→ RESUME（R・大文字）の動作確認
9. 必要なら k#### を調整（例：k5000）
10. 必要なら F でクリーン初期化 → 再設定
```

## 6. よくある質問（FAQ）

### Q1. v1.73e からの更新で F（初期化）は必要？
→ **原則不要。** EEPROM レイアウトは変わっていないため、旧設定がそのまま使えます。

### Q2. STOP 後に `r` を押しても復帰しない
→ v2.01 では RESUME は **大文字 `R`** です。`R` を入力してください。

### Q3. 旧基板（v1.73e 配線）に v2.01 を書いたら動かない
→ ピンアサインが異なるため誤動作します。**v1.73e スケッチに戻してください。**  
　Ver.5 基板への移行が確認できてから v2.01 を使用してください。

### Q4. BUSY 判定が逆っぽい
→ `g0（LOW=busy）` / `g1（HIGH=busy）` を確認。  
　`q` で現在の極性を確認可能。

### Q5. D13 に接続していたものが誤動作する
→ v2.01 では D13 は SoftwareSerial（DFPlayer TX 受信）に変わっています。  
　旧配線（抑止 LED）をそのまま D13 に接続すると通信干渉します。  
　**LED を D6 へ移設してください。**

--------------------------------------------------------------------

## 7. まとめ

- v2.01 は **Ver.5 基板専用**。旧基板への書き込みは不可。
- EEPROM レイアウトは変わらず、**旧設定を引き継いで動作**。
- RESUME コマンドが **`r` → `R`（大文字）** に変更。それ以外のコマンドは同一。
- v1.73e の全機能（postTxIgnore / catch-up / A0観測継続 / 静寂ガード）を完全継承。
