# DS3231 + AT24C32 モジュール 接続・運用ガイド

対象バージョン: OpenCCVoice v2.10 以降  
対象基板: Ver.5  
最終更新日: 2026-03-11

---

## 1. モジュールの概要

市販の「DS3231 + AT24C32」一体型 I²C モジュールには、2つのデバイスが搭載されています。

| デバイス | 役割 | I²C アドレス（既定） |
|----------|------|----------------------|
| **DS3231** | リアルタイムクロック（RTC） | 0x68（固定） |
| **AT24C32** | 外部 EEPROM（32Kbit / 4KB） | 0x57（A0〜A2 全 LOW 時） |

**v2.20 では DS3231（RTC）と AT24C32（EEPROM）の両方を使用します。**

| 用途 | デバイス |
|------|----------|
| 時刻管理（正時アライン） | DS3231 |
| 設定の永続保存（内蔵EEPROMとの二重保存） | AT24C32 |

DS3231 は高精度 RTC チップです。コイン電池（CR2032）でバックアップされ、  
電源断中も時刻を保持し続けます。**時刻の自動取得機能はありません。**  
初回および電池交換後に `T` コマンドで時刻を設定する必要があります。

---

## 2. 基板への接続（J5 コネクタ）

Ver.5 基板には **J5 コネクタ**が実装済みです。  
DS3231 モジュールを J5 に差し込むだけで接続完了です。**配線の追加は不要です。**

```
基板 J5              DS3231 モジュール
┌─────────┐          ┌──────────┐
│ 1: SLC  │ ──────── │ SLC(SCL) │ ── Arduino A5
│ 2: SDA  │ ──────── │ SDA      │ ── Arduino A4
│ 3: VCC  │ ──────── │ VCC      │
│ 4: GND  │ ──────── │ GND      │
└─────────┘          └──────────┘
```

> **注意**: J5 の 1 ピン（SLC）と DS3231 モジュールの向きを確認してから挿入してください。

---

## 3. ハードウェアの注意点

### プルアップ抵抗について

Ver.5 基板には I²C プルアップ抵抗が実装済みです（C12 付近）。  
DS3231 モジュール側にも 4.7kΩ のプルアップが搭載されている場合がありますが、  
**二重になっても通常は問題なく動作します。**

### AT24C32 のアドレスジャンパについて

DS3231 モジュール上の AT24C32 には、I²C アドレスを変更するジャンパ（A0/A1/A2）が  
ある場合があります。

- **既定（ジャンパ未ショート）**: アドレス 0x57
- Ver.5 基板上には AT24C32 は実装されていないため、**アドレス競合は発生しません。**
- ジャンパはそのまま（未ショート）で使用してください。

## 4. 起動時の確認

モジュールを接続して電源を入れると、起動ログに以下が表示されます。

### DS3231 が正常に認識された場合

```
[RTC] DS3231 found.
[EEPROM] Settings Loaded.
[START] OpenCCVoice v2.10 (RTC-Aligned Periodic, Ver.5 pinmap)
[RTC] 2000/01/01 00:00:00  Align=ON(RTC)    ← 時刻未設定時はこの表示
```

### DS3231 が認識されない場合（未接続・故障）

```
[RTC] DS3231 not found -> millis() fallback.
[START] OpenCCVoice v2.10 ...
[RTC] N/A(no RTC)  Align=OFF(millis)
```

この場合は millis() 相対動作にフォールバックし、従来通り動作します。

## 5. 初回セットアップ手順

DS3231 を接続したら、最初に時刻を設定します。

### ① シリアルモニタを開く

Arduino IDE または任意のターミナルソフトで  
**115200 bps / 8N1 / 改行なし（または LF）** で接続します。

### ② 現在時刻を設定する（`T` コマンド）

書式: `T` + `YYYY` + `MM` + `DD` + `HH` + `mm` + `ss`（計15文字、スペースなし）

```
T20260311143000
```

上記は「2026年03月11日 14時30分00秒」の意味です。

**入力のコツ**: 時報の数秒前に文字を入力しておき、  
Enterキー（送信）のタイミングを時報に合わせると精度が上がります。

### ③ 設定確認（`q` コマンド）

```
q
```

以下のように表示されれば設定完了です。

```
[RTC] 2026/03/11 14:30:05  Align=ON(RTC)
[CFG] EEPROM_VER=5 SRC=DIGITAL(LOCK) MIN=500 MAX=3900 PER(min)=30
      ... QUIET(ms)=2000 RTC_ALIGN=ON
```

- `[RTC]` 行に現在時刻が表示されていること
- `Align=ON(RTC)` が表示されていること（RTCアライン動作中）

### ④ 周期IDの設定（`p` コマンド）

正時アラインで動作させたい周期を設定します。

```
p15     → 毎時 :00 / :15 / :30 / :45 に送出
p10     → 毎時 :00 / :10 / :20 / :30 / :40 / :50 に送出
p30     → 毎時 :00 / :30 に送出
p0      → 周期ID 停止
```

設定後、次の送出時刻まで待機します。`q` コマンドで現在の設定を確認できます。

---

## 6. コマンドリファレンス（RTC関連）

### `T` — RTC 時刻設定

| 項目 | 内容 |
|------|------|
| 書式 | `TYYYYMMDDHHmmss`（15文字、スペースなし） |
| 例 | `T20260311143000` → 2026/03/11 14:30:00 |
| タイムアウト | 2秒以内に14桁の数字が届かない場合は無効 |
| 設定後 | 次回周期ID発火時刻を即座に再計算 |

**エラーメッセージ一覧:**

| 表示 | 原因 |
|------|------|
| `[RTC] T: timeout` | 2秒以内に14桁届かなかった |
| `[RTC] T: invalid datetime` | 日付・時刻の値が範囲外 |
| `[RTC] T: DS3231 not found` | モジュールが認識されていない |
| `[RTC] T: write failed` | I²C 書き込み失敗 |

---

### `u` — RTCアライン ON/OFF

| コマンド | 動作 |
|----------|------|
| `u1` | RTCアライン有効（既定）。DS3231接続かつp##が60の約数のとき正時アライン動作 |
| `u0` | RTCアライン無効。millis() 相対動作に切替（v2.01互換） |

設定は EEPROM に保存されます。

---

### `q` — 設定一覧（RTC関連の表示）

```
[RTC] 2026/03/11 14:23:45  Align=ON(RTC)
```

| 表示 | 意味 |
|------|------|
| `2026/03/11 14:23:45` | DS3231 から読んだ現在時刻 |
| `Align=ON(RTC)` | RTCアライン動作中（正時基準） |
| `Align=OFF(millis)` | millis() 相対動作（RTC未接続またはu0） |
| `N/A(no RTC)` | DS3231 が認識されていない |
| `N/A(read err)` | DS3231 への I²C 読み取り失敗 |

---

### `p` — 周期ID設定（RTCアライン対応）

60の約数を設定したとき、DS3231 接続かつ `u1` であれば自動的に正時アライン動作になります。

| 設定値 | アライン | 送出タイミング |
|--------|----------|----------------|
| `p10` | ○ | 毎時 :00/:10/:20/:30/:40/:50 |
| `p12` | ○ | 毎時 :00/:12/:24/:36/:48 |
| `p15` | ○ | 毎時 :00/:15/:30/:45 |
| `p20` | ○ | 毎時 :00/:20/:40 |
| `p30` | ○ | 毎時 :00/:30 |
| `p60` | ○ | 毎時 :00 |
| `p7`  | ✗ | millis() 相対（7分おき） |
| `p0`  | — | 周期ID 停止 |

## 7. 運用上の注意

### 電池切れ時の対応

DS3231 のコイン電池（CR2032）が切れると、時刻が `2000/01/01 00:00:00` 付近に  
リセットされます。`q` で確認し、`T` コマンドで再設定してください。

電池切れの目安は **モジュールのボタン電池寿命（数年）** ですが、  
運用開始時に `q` で時刻を確認する習慣をつけることを推奨します。

### 長期ドリフト補正

プログラムは **1分ごとに DS3231 から時刻を再取得**し、  
Arduino の millis() と DS3231 の時刻のずれを自動補正します。  
手動での定期的な時刻合わせは不要です。

### 時刻設定の精度

`T` コマンドは手打ちのため、数秒の誤差が生じることがあります。  
周期ID の送出タイミングは「毎正時アライン」のため、  
数秒の設定誤差は次の周期（最大1時間以内）のうちに自動収束します。

## 8. トラブルシューティング

**● `Align=OFF(millis)` になる（正時アラインにならない）**
1. `q` で `N/A(no RTC)` が出ていないか確認 → J5 コネクタの接続を確認
2. `q` で `RTC_ALIGN=OFF` になっていないか確認 → `u1` を入力
3. `p##` の値が 60 の約数か確認 → `p10`/`p15`/`p30` 等を使用

**● `[RTC] T: DS3231 not found` と出る**
- J5 コネクタの向きと挿入を確認
- モジュールの VCC/GND が正しく接続されているか確認

**● 時刻がすぐにリセットされる**
- DS3231 モジュールのコイン電池（CR2032）を確認・交換

**● 周期IDが設定時刻より数秒ずれる**
- `T` コマンド入力時の誤差です。次の周期で自動収束します
- より正確に合わせたい場合は、時報の直前に文字を入力し送信タイミングを合わせてください

## 9. 仕様まとめ

| 項目 | 内容 |
|------|------|
| DS3231 I²C アドレス | 0x68（固定） |
| AT24C32 I²C アドレス | 0x57（設定の二重保存先） |
| 接続コネクタ | J5（基板右端、4ピン） |
| 使用ライブラリ | Wire.h（Arduino標準、外部ライブラリ不要） |
| アライン対象周期 | 60の約数（1/2/3/4/5/6/10/12/15/20/30/60分） |
| ドリフト補正間隔 | 1分 |
| 電池 | CR2032（モジュール付属または別途用意） |
| 時刻設定コマンド | `TYYYYMMDDHHmmss` |
