# **OpenCCVoice Guidance Controller**

取扱説明書 / コマンドリファレンス  
**バージョン: v1.80i**  
**最終更新日: 2026/03/24**  
対象ハード: Arduino Nano (ATmega328P / 5V)  
通信設定: 115200 bps / 8N1 / 改行なし（または LF）

---

## ■ 概要

本機は DMR無線機のID送出を自動制御するコントローラです。  
PCとUSB接続し、シリアルモニタから各種コマンドで設定を変更できます。

全ての設定は EEPROM に自動保存され、電源断でも保持されます。

**v1.80i** では v1.80h のコード品質改善を行いました。主な変更点は以下のとおりです。

- カーチャンク検出時の `busySupUntil` 二重セットを修正（起点A に一本化）
- ver=3 以前からのマイグレーション時の不定値リスクを修正
- `handleStoppedState()` 内のデッドコードを削除
- コメント内の旧用語・内部開発版番号を修正

EEPROM CONFIG_VERSION は 5 のまま変更なし。v1.80h からの書き込みは EEPROM 操作不要です。

**v1.80h** では v1.73f1 からの大規模な仕様刷新を行いました。主な変更点は以下のとおりです。

- カーチャンク判定の明確化（② MAX デフォルト: 3900ms → 1500ms）
- PTT 先行・後行無音時間（PRE/POST）をコマンドで可変化（`j####` / `J####`）
- 抑止ロジックを一本化（連打抑止BURSTを廃止し、`busySupUntil` のみで管理）
- 定周期IDをスキップ仕様に変更（旧: 延期保持 → 新: 到来時に条件不成立なら破棄）
- PRE/POST 待機を絶対時刻比較に変更（ブロッキングによるスキップバグを修正）
- ログレベルコマンドを `l0/l1/l2/l3` に変更、STOP復帰コマンドを `R`（大文字）に変更

## ■ 本バージョン（v1.80i）の主な変更点

### 【仕様番号とコマンド対応】

本バージョンから、コア動作に関わる主要パラメータに仕様番号を付与しています。

| 番号 | 内容 | コマンド | デフォルト |
|------|------|---------|-----------|
| ① | カーチャンク最小受信長 | `n####` | 500ms |
| ② | カーチャンク最大受信長 | `b####` | 1500ms |
| ③ | PTT先行無音時間（PRE） | `j####` | 1000ms |
| ④ | PTT後行無音時間（POST） | `J####` | 1000ms |
| ⑤ | 抑止時間 | `r####` | 10000ms |
| ⑥ | 定周期間隔 | `p##` | 30分 |

### 【抑止ロジックの刷新】

旧来の「長話抑止（longSupUntil）」「連打抑止（burstSupUntil）」「送信直後ガード（postTxIgnore）」を廃止し、⑤抑止（busySupUntil）に一本化しました。

**⑤抑止の起点：**

- **起点A**: ④ POST 終了の瞬間（カーチャンクID送出後、受信中でない場合）
- **起点B**: ② 超え受信（通常会話）の終了の瞬間
- 受信中に POST が終わった場合は起点B が起点A を上書き

### 【定周期IDのスキップ仕様】

受信中・抑止中・PTT中に周期が到来したら、その回をスキップ（破棄）します。
旧仕様の「条件不成立時に periodicDue を保持して延期」から変更されました。

> **注意**: スキップが頻発する場合は `k####` を短くするか、`p##` の周期を見直してください。

### 【PRE/POST バグ修正】

旧実装では `Serial.parseInt()` のブロッキング中に `millis()` が進み、PRE 無音時間がスキップされる場合がありました。`Serial.setTimeout(50)` を `setup()` で一度だけ設定し、PRE/POST 待機を絶対時刻比較（`pttPreEndAt` / `pttPostEndAt`）に変更することで修正しました。

## 2. コマンド詳細解説

**[m：モード設定]**  
m0 … D6（デジタルBUSY）固定  
m1 … A0（アナログ）固定  
m2 … AUTO（D6/A0 を観測し優位側へ自動固定）  
※ AUTO中は D6/A0 どちらの入力でも ID が出る

**[b / n：① ② カーチャンク検出窓]**

```
dur < n####              → ノイズ扱い（無視）
n#### ≤ dur < b####      → カーチャンク → ID送出
dur ≥ b####              → 通常会話 → ⑤抑止開始（起点B）
```

n#### … dur < n#### はノイズ扱い（デフォルト 500ms）  
b#### … dur ≥ b#### は通常会話と判定（デフォルト 1500ms）

**[j / J：③ ④ PTT 先行・後行無音時間]**  
j#### … PTT ON から DFPlayer 再生開始までの先行無音時間（デフォルト 1000ms）  
J#### … DFPlayer 再生完了から PTT OFF までの後行無音時間（デフォルト 1000ms）  
どちらも EEPROM に保存される

**[r：⑤ 抑止時間]**  
r#### … 抑止が発動してからの抑止継続時間（ms）  
r0 … 実質的な抑止無効（送信後抑止を無くしたい場合）  
デフォルト 10000ms（10秒）

**[p / k：⑥ 定周期ID]**  
p## … ##分ごとにトラック002/003を交互送出。p0 で停止。  
k#### … 定周期IDを送出する前に「BUSY OFFからの静寂期間（ms）」を要求する静寂ガード。  
　　　　条件不成立の場合はその回をスキップ（破棄）。

- 例：k2000 → BUSY 終了後 2秒静かなら送出（デフォルト）
- 例：k5000 → より強い割り込み防止
- k0 → 静寂ガード無効

**[w：AUTO観測期間]**  
AUTO_WINDOW 分観測 → 優位側へ固定（D13 高速点滅で通知）

**[L / G / a：A0アナログ判定パラメータ]**  
L### … この値を下回ったとき BUSY 開始と判定（デフォルト 300）  
G### … この値を上回ったとき BUSY 終了と判定（デフォルト 700）  
a#### … BUSY 終了判定後も a#### ms は BUSY 状態を保持（スケルチテール対策）（デフォルト 800ms）

**[d：DFPlayer フェイルセーフ]**  
DFPlayer BUSY が戻らない場合、d#### ms 経過で強制 PTT OFF。d0 で無効化。

**[g：BUSY 極性]**  
g0 = LOW=受信（アクティブLOW）  
g1 = HIGH=受信（アクティブHIGH）（既定）

**[x / R：停止と再開]**  
x … 全動作停止（Safe Stop）  
R … 停止中の復帰（STOP中のみ有効）

**[F：Factory Reset]**  
全設定を初期値に戻し EEPROM 保存。MCU は動き続ける。

**[V：バージョン確認]**  
出力例：`[VER] OpenCCVoice v1.80i (EEPROM_VER=5)`

**[Z：ソフトウェアリセット]**  
ウォッチドッグタイマー（15ms）で MCU を再起動。EEPROM は変更しない。  
`F` の後に `Z` を実行すると完全クリーン起動になる。

| 操作 | EEPROM | MCU | 用途 |
|------|--------|-----|------|
| `F` のみ | 初期値で上書き | 動き続ける | 設定のみリセット |
| `Z` のみ | 変化なし | 再起動 | 設定保持のまま再起動 |
| `F` → `Z` | 初期値で上書き | 再起動 | 完全クリーン起動 |

**[l0〜l3：ログレベル]**  
l0=OFF / l1=MIN（起動時デフォルト）/ l2=FULL / l3=DBG  
EEPROM には保存されない。起動時は常に l1=MIN。

**[h：ヘルプ]**  
コマンド一覧をシリアル出力する。

## 3. 設定値解説（目的・実態・調整指針）

### 【m：BUSYソース選択】

無線機のBUSY信号をどのピンで受けるかを選ぶ。

- `m0`（D6）：デジタル入力。無線機のBUSY出力を直接接続する場合。
- `m1`（A0）：アナログ入力。スケルチ電圧等をヒステリシス判定で検出する場合。
- `m2`（AUTO）：起動後 `w##` 分間、D6エッジ数とA0イベント数を比較し、反応の多い側へ自動固定。固定後はEEPROMへ保存され再起動後も維持される。

固定配線が済んでいる場合は `m0` か `m1` を明示的に指定しておくのが安全。`m2` は初期設置・配線確認時に便利。

---

### 【① n / ② b：カーチャンク検出窓】

BUSYの継続時間がこの範囲に収まった場合を「カーチャンク」と判定し、トラック001（ID音声）を送出する。

- `n####`（デフォルト 500ms）：これより短い受信はノイズとみなし無視する。
- `b####`（デフォルト 1500ms）：これ以上の受信は通常会話とみなし、⑤抑止（起点B）に入る。

調整指針：カーチャンクが検出されない場合は `n` を小さく、通常会話中に誤って ID が出る場合は `b` を大きくする。

---

### 【③ j / ④ J：PTT 先行・後行無音時間】

- `j####`（デフォルト 1000ms）：PTT ON から DFPlayer への再生コマンド送出までの先行無音時間。相手局が受信体制に入るまでの余裕時間。
- `J####`（デフォルト 1000ms）：DFPlayer 再生完了から PTT OFF までの後行無音時間。音声が確実に伝わるまでの余裕時間。

両パラメータとも EEPROM に保存される。無線機の特性や運用環境に合わせて調整する。

---

### 【⑤ r：抑止時間】

カーチャンク検出後または通常会話終了後に発動する抑止の継続時間。

- デフォルト 10000ms（10秒）
- `r0` で実質的な送信後抑止無効

**抑止の起点：**
- 起点A: ④ POST 終了の瞬間（カーチャンクID送出後・受信中でない場合）
- 起点B: ② 超え受信（通常会話）終了の瞬間
- POST 終了時に受信中の場合は、起点B が起点A を上書きする

混信環境では `r15000` 程度に延ばすと誤発火が減る。

---

### 【⑥ p / k：定周期ID】

- `p##`（分）：`##` 分ごとにトラック002/003を交互送出。`p0` で停止。起動時刻基準で等間隔。
- `k####`（ms）：定周期IDを送出する前に「BUSY がOFFになってから `k####` ms 以上の静寂」を要求する静寂ガード。条件不成立の場合はその回をスキップ（破棄）。

デフォルト `k2000`（2秒）。通話が頻繁な環境では `k5000` 程度に延ばすと定時IDの割り込み感が大幅に減少する。

---

### 【w：AUTO観測窓】

`m2`（AUTO）選択時に D6/A0 のどちらを採用するかを判定する観測期間（分）。  
デフォルト 30分。試験時は `w1`〜`w5` で短縮可能。

---

### 【L / G / a：A0アナログ判定パラメータ】

A0 ピンのアナログ電圧（0〜1023）をヒステリシスで BUSY 判定する。

- `L###`（デフォルト 300）：この値を下回ったとき BUSY 開始と判定。
- `G###`（デフォルト 700）：この値を上回ったとき BUSY 終了と判定。
- `a####`（デフォルト 800ms）：BUSY 終了判定後も `a####` ms は BUSY 状態を保持（スケルチテール対策）。

ノイズが多い環境では L を小さく、G を大きくしてヒステリシス幅を広げると安定する。

---

### 【d：DFPlayer フェイルセーフ】

DFPlayer が再生を開始したまま BUSY ピンが戻らない（張り付き）場合に、`d####` ms 経過で強制的に PTT OFF する安全機構。

- デフォルト 20000ms（20秒）：音声ファイルの最大長より長めに設定するのが原則。
- `d0`：無効化（通常は非推奨）。

---

### 【g：BUSY 極性】

無線機の BUSY 出力の論理を合わせる。配線変更なしに対応できる。

- `g0`：LOW=受信（アクティブLOW）
- `g1`：HIGH=受信（アクティブHIGH）（デフォルト）

極性を間違えるとカーチャンク・通常会話の判定が完全に逆転するため、初期設定時に必ず `q` で確認すること。

## 5. フェイルセーフ（DFPlayer BUSY異常）

DFPlayer BUSY が戻らない場合、**d#### ms 経過後に強制 PTT OFF**。

- デフォルト：d20000（20秒）
- d0：無効化

## 6. トラブルシューティング

**● IDが出ない**

- Safe Stop 中（`x`）→ `R` で復帰
- 通常会話受信中（dur ≥ b####）→ ⑤抑止中
- D13 点灯中（⑤抑止中）では動作しない
- 定周期IDがスキップされている → `k####` を短くするか `p##` を見直す

**● ID が止まらない**

- `r####` を増やす
- `n####` を大きくする（ノイズの誤検知防止）

**● 送信後に ID が誤発火する**

- ⑤ 抑止時間（`r####`）を増やす
- `b####` を小さくして通常会話を確実に ② 超えと判定させる

**● 定周期IDが送出されない**

- `k####` が長すぎる可能性 → `k2000` 〜 `k0` で試す
- `p##` が 0 になっていないか `q` で確認

**● 音声が途中で切れる**

- `d####` を延長（d30000 など）
- SDカード内のファイル階層（`/mp3/0001.mp3` 等）を確認
- D7（BUSY）が途中 HIGH になっていないか確認

**● BUSY判定が逆**

- `g0/g1` の設定確認（`q` で `POL=LOW=busy` / `POL=HIGH=busy` を確認）
- D6 は INPUT_PULLUP 必須

**● PRE/POST 時間が短すぎる**

- `j####` / `J####` を増やす
- v1.80h 以降はブロッキングによるスキップバグが修正済み

## 7. 配線メモ（Ver.5 PCB）

```
DFPlayer TX → D10（Arduino RX）
DFPlayer RX ← D11（Arduino TX）
DFPlayer BUSY（LOW=再生中）→ D7
D7ミラー（反転）→ D2
TM BUSY → D6（g0/g1 で極性指定）
PTT → D5（HIGH=送信）
LED → D4（D6） / D12（A0） / D13（抑止/AUTO）
テストSW → D3（INPUT_PULLUP）
```

## 8. EEPROM について

### 【CONFIG_VERSION=5（v1.80i）】

- v1.80i の EEPROM CONFIG_VERSION は 5 です（v1.80h から変更なし）
- v1.73系（CONFIG_VERSION=4）からスケッチを書き込むと、起動時に自動マイグレーションが実行されます
- v1.80h からの書き込みは EEPROM 操作不要です

### 【自動マイグレーション内容（ver=4 → ver=5）】

| 処理 | 内容 |
|------|------|
| `pttPreMs` / `pttPostMs` を補完 | 1000ms で補完 |
| `busyMax` が旧デフォルト（3900ms）の場合 | 1500ms に更新 |
| `txSupMs` が旧デフォルト（3000ms）の場合 | 10000ms に更新 |
| 不正値の安全補完 | 極性・タイムアウト・静寂時間等 |

### 【起動時確認ログ】

正常アップグレード（ver=4 → ver=5）時：
```
[EEPROM] Version mismatch: stored=4 expected=5
[EEPROM] Migration done.
[EEPROM] Settings Loaded.
[START] OpenCCVoice v1.80i
```

初回起動またはデータ破損時：
```
[EEPROM] No/Other Data. Init defaults.
[EEPROM] Settings Loaded.
[START] OpenCCVoice v1.80i
```
