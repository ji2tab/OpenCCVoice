# CHANGELOG — OpenCCVoice ID Guidance Controller

本プロジェクトは、Arduino Nano (ATmega328P, 5V) 上で動作する DMR無線機の ID送出支援コントローラです。

記法: Keep a Changelog 準拠 / 日付: JST

## v2.30 — v1.80i コア搭載 + v2.24f RTC・ログ統合版 (2026-04-28)

### Added
- **v1.80i の3つの革新をコア搭載**（大幅改善）
  - **絶対時刻比較** → PTT PRE/POST のタイミングがより確実
  - **抑止起点統一** → busySupUntil で単一タイマー管理（複雑ロジック削除）
  - **ブロッキング対策** → Serial.setTimeout(50) で parseInt() 最大50ms制限

- **EEPROM CONFIG_VERSION = 7 へ更新**
  - 自動マイグレーション対応: v2.24f (ver=6) / v1.80i (ver=5) からの設定継承
  - マイグレーション時に削除フィールドは自動補完

- **ログレベル拡張**
  - 新規: `l4` (LOG_VERBOSE) → v2.30固有の詳細デバッグ出力
  - 既存: `l0/l1/l2/l3` は v2.24f から継続

### Changed
- **コマンド削除（v2.30 で内部固定化）**
  - `j####` / `J####` → PTT PRE/POST は内部固定1000ms（ユーザー変更不可）
  - `i####` → IDLE_MIN_MS は内部固定200ms（ユーザー変更不可）
  - `s0/s1` / `t0/t1` → 抑止ロジック統合（常時有効・ユーザー変更不可）
  - `h` → ヘルプ廃止（代わりに `q` / `V` を使用）

- **PTT 制御メカニズム（v1.80i 由来）**
  - 相対時間比較から絶対時刻比較へ変更
  - `pttPreEndAt = now + PTT_PRE_MS` → 固定1000ms
  - `pttPostEndAt = now + PTT_POST_MS` → 固定1000ms
  - Serial.read() ブロッキング時のずれを根本解決

- **抑止ロジック（v1.80i 由来）**
  - 複数タイマー（suppressOn/txAfSupOn/postTxIgnore）から単一タイマーへ
  - `busySupUntil` を絶対時刻で管理
  - 起点A（POST終了+BUSY OFF）と起点B（受信終了）を統一管理

### Notes
- ハードウェア（ピンマップ）は Ver.5 と完全踏襲（変更なし）
- DS3231 RTC / AT24C32 EEPROM は v2.24f と同等に対応
- v2.24f との完全下位互換（設定自動引き継ぎ）
- v1.80i の安定性・正確性の大幅向上を v2.30 で提供

## v2.24f — V/Z コマンド追加版 (2026-03-18)

### Added
- **`V` コマンド：バージョン確認**（v1.73f1 由来）
  - スケッチバージョンと EEPROM_VER を即時表示。
  - 出力例：`[VER] OpenCCVoice v2.24f (EEPROM_VER=6)`
  - v2.x 系では `v` をイベントログ表示に使用しているため大文字 `V` を採用。

- **`Z` コマンド：ソフトウェアリセット**（v1.73f1 由来）
  - ウォッチドッグタイマー（WDT, 15ms）による MCU 再起動。
  - EEPROM の内容は変更しない（設定は保持されたまま再起動）。
  - `F` → `Z` の順で実行すると完全クリーン起動が可能。
  - 実行後はシリアル出力を吐き出してから WDT 発火（`delay(100)` 挿入）。

  | コマンド | EEPROM | MCU | 用途 |
  |---------|--------|-----|------|
  | `F` のみ | 初期値で上書き | 動き続ける | 設定のみリセット |
  | `Z` のみ | 変化なし | 再起動 | 設定保持のまま再起動 |
  | `F` → `Z` | 初期値で上書き | 再起動 | 完全クリーン起動 |

### Notes
- 機能的な変更はありません。v2.24 の全機能を継承。
- EEPROM CONFIG_VERSION = **6（変更なし）**。`F` コマンド不要。
- `avr/wdt.h` をインクルード追加（WDT 制御に使用）。
- PTT 出力中に `Z` を実行すると WDT ハードリセットにより PTT が即解放される。
  意図せず実行しないこと。

## v2.23 — TX/RX ピン修正・コンパイルエラー修正版 (2026-03-12)

### Fixed
- **DFPlayer TX/RX ピンアサインのバグを修正**（v2.22 より）

  | | ARD_RX（← DFPlayer TX） | ARD_TX（→ DFPlayer RX） |
  |---|---|---|
  | **誤（v2.21以前）** | D13 | D12 |
  | **正（v2.23）** | D12 | D13 |

- **Arduino IDE でのコンパイルエラーを修正**
  - Arduino IDE は `.ino` ファイルのコンパイル前に全関数のプロトタイプ宣言を
    自動生成する。この際 `struct LogHeader` / `struct MyConfig` より前に
    プロトタイプが挿入されてしまい「未宣言」エラーが発生していた。
  - ログ関連コードを `ccvoice_log.h`、設定マイグレーションコードを
    `ccvoice_config.h` に分離することで根本解決。

### 構成ファイル（3ファイルを同一フォルダに置くこと）
```
OpenCCVoice_v2_30.ino    メインスケッチ
ccvoice_log.h            イベントログ関連
ccvoice_config.h         設定マイグレーション関連
```

### Notes
- 機能的な変更はありません。v2.21 の全機能を継承。
- v2.20 / v2.21 / v2.22 は廃止（GitHub からも削除）。機能・仕様の記録は CHANGELOG に保持。
- EEPROM CONFIG_VERSION = **6（変更なし）**。`F` コマンド不要。

## v2.21 — AT24C32 イベントログ記録対応版 (2026-03-11) ⚠️ 廃止

### Added
- **AT24C32 へのイベントログ記録機能を追加**
  - ログ領域: AT24C32 アドレス 0x0048〜（リングバッファ、最大 448件）
  - 448件超過後は古いものから上書き（9バイト/件）

- **記録イベント一覧**

  | 種別 | 表示 | 記録タイミング | 付加データ |
  |------|------|----------------|-----------|
  | 起動 | BOT | 起動時 | EEPROM ver |
  | 周期ID送出 | PER | Track2/3送出時 | Track番号 |
  | カーチャンク | CAR | ID送出トリガー時 | BUSY時間(ms) |
  | 長話抑止 | SUP | 長話抑止発生時 | BUSY時間(ms) |
  | バースト抑止 | BST | バースト抑止発生時 | バースト回数 |

- **`v` コマンド追加**: 直近20件をシリアルモニタに表示
- **`v0` コマンド追加**: ログ全件消去

### Notes
- AT24C32 未接続時はログ記録・表示をスキップ（動作に影響なし）
- EEPROM CONFIG_VERSION = **6（変更なし）**
- ⚠️ **このバージョンは廃止です。v2.30 をご使用ください。**

## v2.10 — DS3231 RTC 正時アライン対応版 (2026-03-11)

### Added
- **DS3231 RTC モジュール対応**（I²C / A4=SDA, A5=SCL）
- **周期ID の「正時アライン」方式を導入**
  - `p##` が60の約数かつ DS3231 接続時 → 毎正時基準で等間隔送出
  - 例：`p15` → 毎時 :00/:15/:30/:45 に送出
  - 60の約数でない値または DS3231 未接続時 → millis() 相対動作
- **`T` コマンド追加**: RTC 時刻設定（例: `T20260311143000`）
- **`u0/u1` コマンド追加**: RTCアライン OFF/ON
- **EEPROM CONFIG_VERSION を 5 に更新**（`rtcAlignOn` フィールド追加）
