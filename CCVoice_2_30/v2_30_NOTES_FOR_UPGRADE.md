# アップグレードガイド — OpenCCVoice v2.30

**バージョン: v2.30（v1.80i コア搭載 + v2.24f RTC・ログ統合）**

---

## v2.24f → v2.30 アップグレード（重要）

**スケッチの差し替え+EEPROM自動マイグレーション**で完了します。

### v2.30 での主な変更

| 項目 | v2.24f | v2.30 | 影響 |
|------|--------|-------|------|
| CONFIG_VERSION | 6 | **7** | 自動マイグレーション |
| PTT制御 | 相対時間 | **絶対時刻比較** | v1.80i 改善搭載 |
| 抑止ロジック | 複雑 | **統一化** | v1.80i 改善搭載 |
| j/J コマンド | ✅可変 | ❌削除 | 内部固定1000ms |
| i コマンド | ✅可変 | ❌削除 | 内部固定200ms |
| s/t コマンド | ✅あり | ❌削除 | 抑止統合 |
| ログレベル | l0/l1/l2/l3 | **l0/l1/l2/l3/l4** | LOG_ERR 追加 |

### アップグレード手順

```
Step 1: 必須ファイル確認
  ├─ OpenCCVoice_v2_30.ino
  ├─ ccvoice_config.h（v2.30対応版）
  └─ ccvoice_log.h（変更なし・v2.24fそのまま使用可）

Step 2: Arduino IDE でスケッチ開く
  └─ OpenCCVoice_v2_30.ino をロード

Step 3: コンパイル・書き込み
  ├─ Verify チェック
  ├─ Upload
  └─ シリアルモニタ 115200bps で確認

Step 4: 起動ログ確認
  ├─ "[EEPROM] Migration done." が表示（v2.24f からの自動変換）
  ├─ V コマンドで "[VER] OpenCCVoice v2.30 (EEPROM_VER=7)" 確認
  └─ q コマンドで設定が継承されていることを確認

Step 5: 動作確認
  ├─ テストSW で ID送出確認
  ├─ DS3231 接続時は RTC アライン動作確認
  └─ AT24C32 接続時はイベントログ記録確認
```

### EEPROM マイグレーション（自動実行）

v2.24f (ver=6) からの自動マイグレーション内容：

```
【削除されるフィールド】
- suppressOn / txAfSupOn → 抑止ロジック統合
- idleMin → 内部固定200ms
- pttPreMs / pttPostMs → 内部固定1000ms

【新規追加フィールド】
- (既存：rtcAlignOn, saveTimestamp → v2.10以降で既存)

【変わらないフィールド】
- busySrc / busyMin / busyMax / periodMin / txSupMs
- a0Low / a0High / a0Hold / autoWinMin / dfpTimeoutMs
- tmBusyActiveHigh / periodQuietMs

【自動補完】
起動時に自動で config.ver = 7 に更新
既存設定はすべて引き継がれます
```

## 削除されたコマンドの対応表

v2.30 では以下のコマンドが廃止されました。

| 廃止コマンド | v2.24f での機能 | v2.30 での対応 |
|-------------|----------------|---------------|
| `j####` | PTT先行時間(PRE) | 内部固定1000ms（変更不可） |
| `J####` | PTT後行時間(POST) | 内部固定1000ms（変更不可） |
| `i####` | 送信直後ガード | 内部固定200ms（変更不可） |
| `s0/s1` | 抑止全体ON/OFF | 常時有効（ユーザー変更不可） |
| `t0/t1` | 送信後抑止ON/OFF | `r0` で実質OFF |
| `h` | ヘルプ表示 | 削除（q で設定確認、V でバージョン確認） |

### 対応手順

**もし v2.24f で j/J/i/s/t/h を使用していた場合：**

```
1️⃣  j#### で PTT PRE を設定していた
   → v2.30 では固定1000ms になります
   → 必要に応じて q で設定を確認

2️⃣  J#### で PTT POST を設定していた
   → v2.30 では固定1000ms になります

3️⃣  i#### でアイドル時間を設定していた
   → v2.30 では固定200ms になります

4️⃣  s0/s1 で抑止をON/OFF していた
   → v2.30 では抑止は常時有効です
   → OFF したい場合は r0 コマンドを使用

5️⃣  t0/t1 で送信後抑止をON/OFF していた
   → 同上、r0 を使用してください

6️⃣  h でヘルプを表示していた
   → q コマンドで設定確認、V でバージョン確認をしてください
```

## v2.30 の主要な改善点（v1.80i由来）

### ① 絶対時刻比較（v1.80h/v1.80i確立 → v2.30継承）

PTT制御が「相対時間比較」から「絶対時刻比較」に改善されました。

```
【効果】
- Serial.read() ブロッキングで now がずれても PRE/POST が確実
- DFPlayer 再生タイミングがより正確
- Serial.setTimeout(50) で parseInt() ブロッキング上限設定
```

### ② 抑止起点統一（v1.80i確立 → v2.30継承）

抑止ロジックが「二重セット」から「統一管理」に改善されました。

```
【改善点】
- 起点A：POST終了時 + BUSY OFF
- 起点B：通常会話終了時（受信OFF）
- 単一の busySupUntil タイマーで統一管理
- v1.73系の複雑なロジック（連打抑止・送信直後ガード）を統合
```

### ③ ブロッキング対策（v1.80h/v1.80i確立 → v2.30継承）

Serial通信のブロッキング問題が対策されました。

```
【対策】
- Serial.setTimeout(50) → parseInt() 最大50msに制限
- 旧版での「数秒ブロック」問題を根本解決
```

## 既存 v2.10〜v2.24 からのアップグレード

すべてのバージョンから v2.30 へのアップグレードは**自動マイグレーション対応**です。

### v2.01 → v2.30（Ver.4 基板の場合）

⚠️ **基板を Ver.5 に交換してください。**
v2.01 は Ver.4 基板用。v2.30 は Ver.5 基板用です。

## v2.30 特有の確認項目

アップグレード後、以下を確認してください：

```
□ 起動ログで "v2.30" が表示されている
□ V コマンドで EEPROM_VER=7 が表示
□ q コマンドで既存設定が表示される
□ テストSWでID送出動作確認
□ r コマンド（抑止時間）が機能している
□ DS3231接続時: RTC時刻が表示される
□ AT24C32接続時: イベントログが記録される
```

```
旧: h キー → ヘルプ表示
新: q キー → 全設定表示
   V キー → バージョン表示
```

で対応してください。

## トラブルシューティング

### 「EEPROM Version mismatch」と出た

→ **正常です。** 自動マイグレーションが実行されています。
起動ログで「Migration done.」が続いていることを確認してください。

### 設定が引き継がれていない

1. `F` → `Z` で完全リセット
2. 再度 v2.30 を書き込み
3. `q` で設定が初期値に戻ったことを確認

### j/J コマンドが効かない

→ **正常です。** v2.30 では j/J コマンドは廃止されました。
PRE/POST は内部固定1000msに統一されています。

### h コマンドが効かない

→ **正常です。** v2.30 では h コマンドは廃止されました。
`q` で設定表示、`V` でバージョン表示をしてください。

## まとめ

v2.24f → v2.30 のアップグレードは：

✅ **スケッチの差し替えのみ** — EEPROM初期化不要
✅ **設定は自動引き継ぎ** — v2.24f の設定がすべて保持
✅ **v1.80i の改善搭載** — より堅牢なPTT制御・抑止ロジック
✅ **完全下位互換** — v2.24f のハードウェア・音声ファイル・RTC・ログがそのまま使用可能

**推奨：起動後、かならず q と V コマンドで確認してください。**
