【使用方法】
================================================================================

## Step 1: ファイル確認

v2_30_ で始まるすべてのファイルが以下の場所にあります：

/mnt/user-data/outputs/

- v2_30_*.md      → ドキュメント（Markdown形式）
- v2_30_*.h       → ヘッダーファイル（C++）
- OpenCCVoice_v2_30.ino  → メインスケッチ

## Step 2: ファイル利用

【Arduino IDE での使用】

1. OpenCCVoice_v2_30.ino をダウンロード
2. 同じフォルダに以下の2ファイルを配置
   - v2_30_ccvoice_config.h
   - v2_30_ccvoice_log.h
3. Arduino IDE で OpenCCVoice_v2_30.ino を開く
4. ボード: Arduino Nano (ATmega328P)
5. コンパイル・書き込み

【ドキュメント参照】

起動順序：
1. v2_30_README.md → 全体概要
2. v2_30_NOTES_FOR_UPGRADE.md → アップグレード手順
3. v2_30_CHANGELOG.md → 変更詳細
4. v2_30_SPECIFICATION.md → 技術詳細
5. その他 → 用途別ガイド

【v2.30 の特徴】
================================================================================

✅ v1.80i の3つの革新をコア搭載
   • 絶対時刻比較 → PTT PRE/POST タイミング精度向上
   • 抑止起点統一 → 複雑ロジック削除
   • ブロッキング対策 → Serial通信安定化

✅ v2.24f との完全下位互換
   • EEPROM 自動マイグレーション
   • DS3231 RTC / AT24C32 EEPROM 継続対応
   • 音声ファイル・ピンマップ変更なし

✅ CONFIG_VERSION = 7
   • v2.24f (ver=6) からの自動マイグレーション
   • v1.80i (ver=5) からの自動マイグレーション

================================================================================
【削除されたコマンド】
================================================================================

v2.30 では以下のコマンドが削除されました（内部固定化）：

- j####  (PTT先行時間/PRE)        → 内部固定1000ms
- J####  (PTT後行時間/POST)       → 内部固定1000ms
- i####  (送信直後ガード)         → 内部固定200ms
- s0/s1  (抑止ON/OFF)             → 常時有効
- t0/t1  (送信後抑止ON/OFF)       → 常時有効（r####で時間制御）
- h      (ヘルプ表示)             → 削除（q/V で代替）

================================================================================
【確認項目】
================================================================================

アップグレード後、以下を確認してください：

□ 起動ログに "[VER] OpenCCVoice v2.30" が表示
□ V コマンドで EEPROM_VER=7 表示
□ q コマンドで既存設定継承確認
□ "[EEPROM] Migration done." が表示（v2.24f からアップグレード時）
□ DS3231 接続時: RTC時刻が表示
□ AT24C32 接続時: イベントログ記録確認
