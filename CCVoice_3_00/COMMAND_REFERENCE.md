# コマンドリファレンス v3.00

OpenCCVoice v3.00 で利用可能な全コマンドの詳細リファレンスです。

**接続条件**: シリアルモニタ 115200bps / 8N1 / 改行なし または LF

---

## 【受信判定】

### `n####` - カーチャンク最小受信長

| 項目 | 内容 |
|------|------|
| 書式 | `n` + 数字（例: `n500`） |
| 範囲 | 100以上 |
| 単位 | ms |
| デフォルト | 500 |
| EEPROM保存 | あり |

**動作**: 受信長がこの値未満の場合は「ノイズ」と判定し、無視。

**使用例**:
```
n500    → 最小500msに設定
n300    → 短いカーチャンクも検知
```

---

### `b####` - カーチャンク最大受信長

| 項目 | 内容 |
|------|------|
| 書式 | `b` + 数字（例: `b1500`） |
| 範囲 | 500以上 |
| 単位 | ms |
| デフォルト | 1500 |
| EEPROM保存 | あり |

**動作**: 受信長がこの値以上の場合は「通常会話」と判定し、起点B 抑止セット。

**使用例**:
```
b1500   → 1.5秒以上は通常会話扱い
b3000   → 3秒以上を通常会話扱いに（カーチャンク幅広）
```

---

## 【送信制御】

### `j####` - PTT先行無音時間（PRE）

| 項目 | 内容 |
|------|------|
| 書式 | `j` + 数字（例: `j1000`） |
| 範囲 | 100以上 |
| 単位 | ms |
| デフォルト | 1000 |
| EEPROM保存 | あり |

**動作**: PTT ON 後、音声再生開始までの無音時間。
無線機が送信状態に切り替わる時間を確保。

**使用例**:
```
j1000   → 1秒（推奨）
j500    → 0.5秒（高速応答）
j2000   → 2秒（古い無線機向け）
```

---

### `J####` - PTT後行無音時間（POST）

| 項目 | 内容 |
|------|------|
| 書式 | `J` + 数字（大文字、例: `J1000`） |
| 範囲 | 100以上 |
| 単位 | ms |
| デフォルト | 1000 |
| EEPROM保存 | あり |

**動作**: 音声再生完了後、PTT OFF までの無音時間。
末尾の音切れを防止。

**使用例**:
```
J1000   → 1秒（推奨）
J500    → 0.5秒
J1500   → 1.5秒（音声末尾の余韻確保）
```

---

## 【抑止】

### `r####` - 抑止時間（SUP）

| 項目 | 内容 |
|------|------|
| 書式 | `r` + 数字（例: `r10000`） |
| 範囲 | 0以上 |
| 単位 | ms |
| デフォルト | 10000 |
| EEPROM保存 | あり |

**動作**: 以下の起点で抑止タイマーをセット。
- **起点A**: PTT POST終了時（受信中でない場合）
- **起点B**: 通常会話終了時（②超え受信終了）

抑止中は カーチャンクID・定周期ID 共にスキップ。

**使用例**:
```
r10000  → 10秒（推奨）
r5000   → 5秒（緩和）
r30000  → 30秒（強化）
r0      → 抑止無効（非推奨）
```

---

## 【定周期ID】

### `p##` - 周期ID間隔

| 項目 | 内容 |
|------|------|
| 書式 | `p` + 数字（例: `p30`） |
| 範囲 | 0以上（0=停止） |
| 単位 | 分 |
| デフォルト | 30 |
| EEPROM保存 | あり |

**動作**: 設定間隔ごとにトラック2/3を交互送出。
60の約数（10/15/30等）かつDS3231接続時は **正時アライン**動作。

**使用例**:
```
p30     → 30分ごと（毎時 :00 / :30）
p15     → 15分ごと（毎時 :00/:15/:30/:45）
p60     → 1時間ごと（毎時 :00）
p7      → 7分ごと（millis相対、非アライン）
p0      → 周期ID停止
```

---

### `k####` - 静寂ガード時間

| 項目 | 内容 |
|------|------|
| 書式 | `k` + 数字（例: `k2000`） |
| 範囲 | 0〜600000 |
| 単位 | ms |
| デフォルト | 2000 |
| EEPROM保存 | あり |

**動作**: BUSY OFF 後、この時間 静寂が継続するまで定周期ID送出を保留。
通話中の周期ID 割り込みを防止。

⚠️ **既知の挙動**: `k0` 設定後の再起動で 2000ms に補完される場合あり。

**使用例**:
```
k2000   → 2秒（推奨）
k5000   → 5秒（厳しめ）
k500    → 0.5秒（緩い）
```

---

## 【BUSY入力】

### `m#` - BUSY入力ソース選択

| コマンド | 動作 |
|---------|------|
| `m0` | DIGITAL（D11）固定 |
| `m1` | A0（アナログ）固定 |
| `m2` | AUTO（観測後に自動選択） |

**動作**: 
- `m0` / `m1` 設定時は autoLocked=true（自動切替なし）
- `m2` 設定時は AUTO_WINDOW(分) 観測後、優位側へ自動固定

**使用例**:
```
m0      → デジタル入力固定
m1      → アナログ入力固定
m2      → 自動選択（推奨：初回設置時）
```

---

### `g#` - TM BUSY極性

| コマンド | 動作 |
|---------|------|
| `g0` | LOW=busy（アクティブLOW） |
| `g1` | HIGH=busy（アクティブHIGH） |

**動作**: D11 入力の論理を反転。

**使用例**:
```
g0      → LOW信号でBUSY
g1      → HIGH信号でBUSY（推奨：オープンコレクタ等）
```

---

## 【A0判定】

### `L###` - A0閾値LOW

| 項目 | 内容 |
|------|------|
| 書式 | `L` + 数字（例: `L300`） |
| 範囲 | 0〜1023 |
| デフォルト | 300 |

**動作**: A0 がこの値未満になるとBUSY検知開始（ヒステリシス）。

---

### `G###` - A0閾値HIGH

| 項目 | 内容 |
|------|------|
| 書式 | `G` + 数字（例: `G700`） |
| 範囲 | 0〜1023 |
| デフォルト | 700 |

**動作**: A0 がこの値より大きくなるとBUSY解除（ヒステリシス）。
`L < G` の関係必須。

---

### `a####` - A0保持時間

| 項目 | 内容 |
|------|------|
| 書式 | `a` + 数字（例: `a800`） |
| 範囲 | 0以上 |
| 単位 | ms |
| デフォルト | 800 |

**動作**: A0 がHIGH閾値を超えても、この時間 BUSY状態を保持。
ノイズによる誤OFFを防止。

---

### `w##` - AUTO観測窓

| 項目 | 内容 |
|------|------|
| 書式 | `w` + 数字（例: `w30`） |
| 範囲 | 1以上 |
| 単位 | 分 |
| デフォルト | 30 |

**動作**: AUTO（m2）モード時の観測時間。
この時間中に D11/A0 のイベント数を計測し、優位側を選択。

---

## 【DFPlayer】

### `d####` - DFPフェイルセーフ時間

| 項目 | 内容 |
|------|------|
| 書式 | `d` + 数字（例: `d20000`） |
| 範囲 | 0〜600000（0=無効） |
| 単位 | ms |
| デフォルト | 20000 |

**動作**: PLAYING突入後、この時間 DFPlayer BUSY が戻らない場合に強制PTT OFF。

**使用例**:
```
d20000  → 20秒（推奨）
d0      → 無効化（非推奨）
d10000  → 10秒（短縮）
```

---

## 【RTC】

### `TYYYYMMDDHHmmss` - RTC時刻設定

| 項目 | 内容 |
|------|------|
| 書式 | `T` + 14桁の数字 |
| 例 | `T20260311143000` |
| タイムアウト | 2秒以内に14桁届かなければ無効 |
| 必要条件 | DS3231 接続時のみ |

**動作**: DS3231 に時刻を書き込み。設定後、次回周期ID 発火時刻を即再計算。

**エラー**:
- `[RTC] T: timeout` ← 入力が遅すぎる
- `[RTC] T: invalid datetime` ← 値が範囲外
- `[RTC] T: DS3231 not found` ← モジュール未認識
- `[RTC] T: write failed` ← I²C 書き込み失敗

**使用例**:
```
T20260507120000  → 2026/05/07 12:00:00
```

---

### `u#` - RTCアライン制御

| コマンド | 動作 |
|---------|------|
| `u0` | RTCアライン無効（millis() 相対動作） |
| `u1` | RTCアライン有効（既定、正時基準） |

**動作**: u1 設定時、`p##` が60の約数かつDS3231接続時に正時アライン動作。
それ以外の条件では自動的にmillis() 相対動作にフォールバック。

## 【ログ（AT24C32）】

### `v` - ログ表示

**動作**: 直近20件をシリアルモニタに表示。

**出力例**:
```
---- EVENT LOG (15/448) ----
No  Time                Event  Data
001 2026/05/07 10:23:45 BOT    ver=7
002 2026/05/07 10:24:10 CAR    BUSY=800ms
003 2026/05/07 10:24:23 PER    Track=2
...
---- END LOG ----
```

**注意**: AT24C32 未接続時は `[LOG] AT24C32 not connected.` を表示。

---

### `v0` - ログ全件消去

**動作**: AT24C32 のログ領域を初期化。

**出力**: `[LOG] Cleared.`

---

## 【ユーティリティ】

### `V` - バージョン表示

**動作**: スケッチバージョン + EEPROM_VER を表示。

**出力例**:
```
[VER] OpenCCVoice v3.00 (EEPROM_VER=7)
```

---

### `q` - 設定一覧表示

**動作**: 全設定値とRTC時刻を表示。

**出力例**:
```
[RTC] 2026/05/07 12:34:56  Align=ON(RTC)
[CFG] EEPROM_VER=7 SRC=DIGITAL MIN=500 MAX=1500 PRE=1000 POST=1000 SUP=10000
      PER(min)=30 QUIET(ms)=2000 A0[L/H]=300/700 HOLD=800 AUTO(min)=30 
      DFP_TO=20000 POL=HIGH=busy
```

---

### `h` - コマンドヘルプ

**動作**: コマンド一覧を表示。

---

### `x` - Safe Stop

**動作**: 全機能を停止（PTT/LED/DFP出力をOFF）。
`R` で復帰可能。

**用途**: メンテナンス時、外部干渉確認時。

---

### `R` - Resume

**動作**: Safe Stop（`x`）からの復帰。

**注意**: 大文字。`r` は抑止時間設定。

---

### `F` - Factory Reset

**動作**: EEPROM を完全初期化（デフォルト値で上書き）。
MCU は再起動しない。

**用途**: 設定リセット、トラブルシュート。

---

### `Z` - ソフトウェアリセット

**動作**: WDT(15ms) で MCU を再起動。EEPROM変更なし（設定保持）。

**シーケンス**:
```
[RESET] SW reset...
（100ms待機後、WDT発火）
[起動ログ再表示]
```

⚠️ **注意**: PTT中に実行するとPTTが即解放されます。

**用途**: 完全クリーン起動には `F` → `Z` の順で実行。

---

### `l#` - ログレベル制御

| コマンド | レベル | 内容 |
|---------|-------|------|
| `l0` | OFF | ログ無効 |
| `l1` | MIN | 最小（PTT, SUP, AUTO等の重要イベント）★起動時デフォルト |
| `l2` | FULL | 標準（PRE/POST完了等を追加） |
| `l3` | DBG | デバッグ（スキップ理由詳細等） |

**注意**: ログレベルは EEPROM に保存されません。起動時は常に `l1` です。

## 【廃止コマンド（v3.00）】

以下のコマンドは v3.00 で廃止されました。入力時は通知メッセージを表示します。

| コマンド | 廃止理由 | 代替手段 |
|---------|---------|---------|
| `s0/s1` | 抑止は常時有効に統一 | なし（無効化不可） |
| `t0/t1` | POST後抑止は常に有効に統一 | なし |
| `i####` | 抑止に統合（busySupUntil） | `r####` で抑止時間調整 |
| `H` | プリセット機能廃止 | 個別コマンドで設定 |

**入力時の出力**:
```
s0
[CMD] Obsolete command (廃止)
```

## 📊 コマンドの組み合わせ例

### 初回セットアップ（基本）

```
m2          → AUTO観測開始
g1          → 極性: HIGH=busy
n500        → 最小受信長 500ms
b1500       → 最大受信長 1500ms
r10000      → 抑止 10秒
p30         → 周期30分
k2000       → 静寂ガード 2秒
q           → 設定確認
```

### DS3231 RTC接続時の追加設定

```
T20260507120000   → 時刻設定
u1                 → アライン有効
p15                → 15分間隔（正時アライン）
q                  → Align=ON(RTC) を確認
```

### 緩和設定（カジュアル運用）

```
r5000       → 抑止 5秒（緩和）
k500        → 静寂ガード 0.5秒（緩い）
b2500       → 通常会話判定を 2.5秒以上に
q
```

### 厳格設定（混雑時）

```
r30000      → 抑止 30秒（強化）
k5000       → 静寂ガード 5秒（厳しめ）
b1000       → 通常会話判定を 1秒以上に
q
```
