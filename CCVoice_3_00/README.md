# OpenCCVoice Guidance Controller v3.00

DMR無線機の自動ID送出コントローラ（Arduino Nano ベース）

## 📋 概要

OpenCCVoice は、DMR無線機の他局カーチャンク（短時間電波）に応答し、
自動的にコールサイン等のID音声を送出する装置です。

### 主な機能

- **カーチャンク検知 → ID送出**: 受信終了後にトラック1（001.mp3）を送出
- **定周期ID**: 設定間隔（分単位）でトラック2/3を交互送出
- **DS3231 RTC正時アライン**: 毎時 :00/:15/:30/:45 等の正時に同期
- **AT24C32 デュアルEEPROM**: 設定の二重保存で耐障害性向上
- **イベントログ**: 最大448件の動作履歴を記録
- **AUTO BUSY判定**: D11デジタル / A0アナログを自動選択

## 🚀 クイックスタート

### 1. Arduino IDE で書き込み

1. `CCVoice_3_0.ino` を Arduino IDE で開く
2. ボード: **Arduino Nano** を選択
3. プロセッサ: **ATmega328P (Old Bootloader)** ※書込み不能の場合は試す
4. 書込み

### 2. シリアルモニタで動作確認

- 速度: **115200 bps**
- 改行: **改行なし** または **LF**

起動ログ例:
```
[RTC] DS3231 found.
[EEPROM] Settings Loaded.
[START] OpenCCVoice v3.00
[CFG] EEPROM_VER=7 SRC=DIGITAL MIN=500 MAX=1500 PRE=1000 POST=1000 SUP=10000 PER(min)=30 ...
```

### 3. RTC時刻設定（DS3231 接続時）

```
T20260311143000
```
→ 2026年03月11日 14時30分00秒 に設定

詳細は `DS3231_CONNECTION_GUIDE.md` 参照。

### 4. 音声ファイル準備

microSDに以下を配置（必ず3ファイル）：
- `001.mp3` ← カーチャンクID
- `002.mp3` ← 定周期ID A
- `003.mp3` ← 定周期ID B

詳細は `AUDIO_FILES_GUIDE.md` 参照。

## 📖 コマンドリファレンス

### 【受信判定】

| コマンド | 機能 | デフォルト | 範囲 |
|---------|------|----------|------|
| `n####` | カーチャンク最小受信長(ms) | 500 | 100以上 |
| `b####` | カーチャンク最大受信長(ms) | 1500 | 500以上 |

**動作**: `n####` ≤ 受信長 < `b####` の場合にカーチャンクと判定。

### 【送信制御】

| コマンド | 機能 | デフォルト | 範囲 |
|---------|------|----------|------|
| `j####` | PTT先行無音時間 PRE(ms) | 1000 | 100以上 |
| `J####` | PTT後行無音時間 POST(ms) | 1000 | 100以上 |

**動作**: PTT ON → PRE → 音声再生 → POST → PTT OFF

### 【抑止】

| コマンド | 機能 | デフォルト |
|---------|------|----------|
| `r####` | 抑止時間 SUP(ms) | 10000 |

**動作**: 
- 起点A: PTT POST終了時 → SUP時間中の送出を抑止
- 起点B: 通常会話（②超え）終了時 → SUP時間中の送出を抑止

### 【定周期ID】

| コマンド | 機能 | デフォルト |
|---------|------|----------|
| `p##` | 周期間隔（分、0=停止） | 30 |
| `k####` | 静寂ガード時間(ms) | 2000 |

**動作**: 
- BUSY OFF後 `k####` ms 経過し、抑止外、IDLE状態のときに送出
- 条件不成立時は破棄（延期しない）
- p## が60の約数（10/15/30等）かつDS3231接続時 → 正時アライン

### 【BUSY入力】

| コマンド | 機能 |
|---------|------|
| `m0` | DIGITAL（D11）固定 |
| `m1` | A0（アナログ）固定 |
| `m2` | AUTO（観測後に自動選択） |
| `g0` | TM BUSY極性: LOW=busy（アクティブLOW） |
| `g1` | TM BUSY極性: HIGH=busy（アクティブHIGH） |

### 【A0アナログ判定】

| コマンド | 機能 | デフォルト |
|---------|------|----------|
| `L###` | A0閾値LOW（busy判定） | 300 |
| `G###` | A0閾値HIGH（idle判定） | 700 |
| `a####` | A0保持時間(ms) | 800 |
| `w##` | AUTO観測窓（分） | 30 |

### 【DFPlayer】

| コマンド | 機能 | デフォルト |
|---------|------|----------|
| `d####` | DFPフェイルセーフ(ms、0=無効) | 20000 |

### 【RTC（DS3231）】

| コマンド | 機能 |
|---------|------|
| `TYYYYMMDDHHmmss` | RTC時刻設定（例: T20260311143000） |
| `u0` | RTCアライン無効（millis相対） |
| `u1` | RTCアライン有効（正時基準） |

### 【イベントログ（AT24C32）】

| コマンド | 機能 |
|---------|------|
| `v` | ログ表示（直近20件） |
| `v0` | ログ全件消去 |

### 【ユーティリティ】

| コマンド | 機能 |
|---------|------|
| `V` | バージョン表示 |
| `q` | 設定一覧表示 |
| `h` | コマンドヘルプ |
| `x` | Safe Stop（全機能停止） |
| `R` | Safe Stopから復帰 |
| `F` | Factory Reset（EEPROM初期化） |
| `Z` | ソフトウェアリセット（WDT、EEPROM保持） |
| `l0` | ログレベル: OFF |
| `l1` | ログレベル: MIN（起動時デフォルト） |
| `l2` | ログレベル: FULL |
| `l3` | ログレベル: DBG |

### 【廃止コマンド】

以下は v3.00 で廃止されました。入力時は `[CMD] Obsolete command (廃止)` を表示。

| 旧コマンド | 廃止理由 |
|----------|---------|
| `s0/s1` | 抑止は常時有効に統一 |
| `t0/t1` | POST後抑止は常に有効に統一 |
| `i####` | 抑止に統合 |
| `H` | プリセット機能廃止 |

## 🎯 動作仕様

### カーチャンク → ID送出

```
[RX] BUSY ON
   ↓ (500ms ≤ 受信長 < 1500ms)
[RX] BUSY OFF
   ↓
[RX] CK dur=800ms -> ID TX
[TX] Track 1 -> PRE start
   ↓ (1000ms PRE)
   ↓ (DFPlayer 再生)
   ↓ (1000ms POST)
[TX] POST done -> IDLE
[SUP] START 10000ms (from POST-end)
```

### 定周期ID（30分間隔の例）

```
00:00 → Track 2 送出
00:30 → Track 3 送出
01:00 → Track 2 送出
01:30 → Track 3 送出
...
```

正時アライン時は時計の正時に厳密に同期。

### 抑止状態

| 条件 | 抑止時間 |
|------|---------|
| 通常会話終了（受信長 ≥ ②MAX） | 10秒（起点B） |
| PTT送信完了 | 10秒（起点A） |

抑止中はカーチャンクID・定周期ID共に**スキップ**。

## 📊 起動ログの読み方

```
[RTC] DS3231 found.                    ← RTC接続確認
[EEPROM] Settings Loaded.              ← 設定読み込み完了
[START] OpenCCVoice v3.00              ← バージョン表示
[CFG] EEPROM_VER=7 SRC=DIGITAL ...     ← 設定一覧
```

異常時：
```
[RTC] DS3231 not found -> millis() fallback.   ← RTC未接続（millis動作）
[EEPROM] Init defaults.                         ← 初回起動 or 設定破損
[EEPROM] Migrated from V6 (internal).          ← v2.24fから自動移行
```

## 🐛 トラブルシューティング

### ID送出が期待通り動かない

1. `q` で設定確認
2. `l3` でデバッグログ有効化
3. シリアルモニタで動作観察

### 周期IDが正時アラインしない

1. `q` で `Align=ON(RTC)` を確認
2. `p##` の値が60の約数（10/15/30等）か確認
3. DS3231が認識されているか確認（`[RTC] DS3231 found.`）

### 設定が保持されない

1. `q` で EEPROM_VER=7 を確認
2. 異常な値がある場合は `F` で初期化
3. それでも問題が続く場合は `Z` で再起動

詳細は `NOTES_FOR_UPGRADE.md` 参照。
