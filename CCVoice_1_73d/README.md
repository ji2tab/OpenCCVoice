

# **OpenCCVoice Guidance Controller**

取扱説明書 / コマンドリファレンス  
**バージョン: v1.73d-Unified-Safe**  
**最終更新日: 2026/01/30**  
対象ハード: Arduino Nano (ATmega328P / 5V)  
通信設定: 115200 bps / 8N1 / 改行なし(またはLF)

***

■ 概要  
本機は DMR無線機のID送出を自動制御するコントローラです。  
PCとUSB接続し、シリアルモニタから各種コマンドで設定を変更できます。

全ての設定は EEPROM に自動保存され、電源断でも保持されます。  
**v1.73c から EEPROM にバージョン管理機能を搭載**し、スケッチ更新時の設定破損を防ぐ仕様になりました。  
**v1.73d では「周期IDの静寂ガード」機能（k####）が新たに追加**され、通話中の割り込み問題を大幅に改善しました。

***

■ 本バージョン（v1.73d）の特徴

【EEPROM バージョン管理（config.ver）】

*   起動時に EEPROM のレイアウト版を判定
*   古いバージョンを自動補完 / 移行（マイグレーション）
*   不正値・未知バージョン → 自動初期化
*   `q` に **EEPROM\_VER=4** と表示（v1.73d の版番号）

【v1.73b/c の強化ポイントも継承】

*   TM BUSY（D6）の極性切替：  
    `g0 = LOW=busy` / `g1 = HIGH=busy`
*   フェイルセーフ（DFPlayer BUSY異常）：  
    `d####` で ms 変更、`d0` で無効化
*   AUTO 判定（m2）：  
    D6 / A0 の優位側を自動固定（EEPROM保存）
*   長話抑止 / バースト抑止 / 送信後抑止
*   BUSYデバウンス、PTTガード、周期ID

【v1.73d 新機能：周期ID 静寂ガード（Quiet Guard）】

*   周期ID（002/003）は、  
    **BUSY がOFFになってから k#### ms 静寂継続した場合のみ送出**
*   BUSY中 / 静寂不足 / 抑止期間中は **延期（periodicDue保持）**
*   新コマンド：`k####`
    *   既定：2000（2秒）
    *   `k0` で従来挙動に近い動作へ
*   `q` に **QUIET(ms)=xxxx** が表示される

2.  コマンド詳細解説

\[m：モード設定]  
m0 … D6（デジタルBUSY）  
m1 … A0（アナログ）  
m2 … AUTO（D6/A0 を観測し優位側へ自動固定）  
※AUTO中は D6/A0 どちらの入力でも ID が出る

\[b：最大受信長]  
b3900（3.9秒）までを短発として受付  
dur ≥ b#### は長話と判定し 10秒抑止（LONG\_SUP）

\[n / i：最小受信長 / 直前アイドル]  
n#### … dur < n#### はノイズ扱い  
i#### … 直前アイドル < i#### は短発無効化

\[s / t / r：抑止ガード]  
s1 … 抑止 ON（長話/バースト検出）  
t1 … 自局送出後、r#### ms BUSY を無視  
r#### … 送信後無視時間

\[p：周期ID]  
p##（分）で 002/003 を交互送出  
絶対時刻基準で等間隔

\[k：周期IDの静寂ガード（v1.73d）]  
周期IDを出すための「BUSY OFF からの静寂期間（ms）」

*   例：k2000 → BUSY 終了後 2秒静かなら送出
*   例：k5000 → より強い割り込み防止
*   k0 → 静寂ガード無効（従来に近い）

\[w：AUTO観測期間]  
AUTO\_WINDOW 分観測 → 優位側へ固定（D13 高速点滅）

\[A0検知（L/G/a）]  
LOW/HIGH閾値＋保持時間でアナログBUSYを安定化

\[d：DFPフェイルセーフ]  
DFPlayer BUSY が戻らない場合、  
d#### ms 経過で強制PTT OFF  
d0 で無効化

\[g：TM BUSY極性]  
g0 = LOW=busy  
g1 = HIGH=busy（既定）

\[x / r：停止と再開]  
x … 全動作停止  
r … 停止中の復帰

\[F：初期値へ]  
全設定を初期化し EEPROM 保存

\[h / 0〜3：ヘルプ・ログ]  
h … コマンド一覧  
0〜3 … ログレベル（NONE/ERR/INF/DBG）

3.  LED表示の意味

\[D4] … D6 BUSY受信時点灯（AUTO中はD12と交互点滅）  
\[D12] … A0 検知時点灯（AUTO中はD4と交互点滅）  
\[D13] … 抑止/短発窓/AUTO固定（高速点滅）表示  
\[D2] … DFPlayer BUSYミラー（反転：再生中=HIGH）

***

4.  フェイルセーフ（DFPlayer BUSY異常）

DFPlayer BUSY が戻らない場合、  
**d#### ms 経過後に強制 PTT OFF**。

*   既定：d20000
*   d0：無効（判定スキップ）

***

5.  トラブルシューティング

● IDが出ない

*   停止中（x）→ r
*   長話（b3900超）→ 抑止
*   D13 点灯中（抑止）では動作しない

● ID が止まらない

*   t1 と r#### を増やす
*   n#### / i#### を大きくする

● 音声が途中で切れる

*   d#### を延長（d20000 など）
*   SDカード階層（/mp3/0001.mp3）を確認
*   D7(BUSY) が途中 HIGH になっていないか

● BUSY判定が逆

*   g0/g1 の設定確認
*   D6 は INPUT\_PULLUP 必須

***

6.  配線メモ（v1.73d）

DFPlayer TX → **D10（Arduino RX）**  
DFPlayer RX ← **D11（Arduino TX）**  
DFPlayer BUSY（LOW=再生中）→ **D7**  
D7ミラー（反転）→ **D2**  
TM BUSY → **D6（g0/g1 で極性指定）**  
PTT → **D5**（HIGH=送信）  
LED → **D4（D6） / D12（A0） / D13（抑止/AUTO）**  
テストSW → **D3（INPUT\_PULLUP）**

***

7.  v1.73d 追加仕様（重要）

【周期ID静寂ガード（k####）】

*   BUSY OFF → **k#### ms** 静寂で周期ID許可
*   BUSY中、静寂不足、抑止期間中は延期
*   `q` で QUIET(ms) を確認可能

【EEPROM バージョン（CONFIG\_VERSION=4）】

*   v1.73c（ver=3）からの更新時、  
    不足項目（periodQuietMs）を 2000ms で補完
*   起動時、自動マイグレーションまたは初期化
*   `EEPROM_VER=4` と表示される
