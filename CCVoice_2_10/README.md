# OpenCCVoice Guidance Controller

取扱説明書 / コマンドリファレンス  
**バージョン: v2.10 — DS3231 RTC 正時アライン対応版**  
**最終更新日: 2026/03/11**  
対象ハード: Arduino Nano (ATmega328P / 5V) **基板 Ver.5**  
通信設定: 115200 bps / 8N1 / 改行なし（またはLF）

---

## ■ 概要

本機は DMR 無線機の ID 送出を自動制御するコントローラです。  
PC と USB 接続し、シリアルモニタから各種コマンドで設定を変更できます。

全ての設定は EEPROM に自動保存され、電源断でも保持されます。  
**v2.10 は DS3231 RTC モジュールに対応し、周期IDを毎正時アライン方式で送出できます。**

---

## ■ v2.10 の特徴・変更点

### 【DS3231 RTC モジュール対応】

基板上の **J5 コネクタ**（SDA/SCL/VCC/GND）に DS3231+AT24C32 一体型モジュールを接続するだけで動作します。

- **未接続・故障時は自動的に millis() 相対動作へフォールバック**（v2.01 互換）
- 起動時に接続確認ログを表示

### 【正時アライン周期ID】

`p##` の値が **60の約数**（10/15/20/30 など）かつ DS3231 接続時、  
**毎正時を基準とした等間隔タイミング**で周期IDを送出します。

| 設定 | 送出タイミング |
|------|----------------|
| `p10` | 毎時 :00/:10/:20/:30/:40/:50 |
| `p15` | 毎時 :00/:15/:30/:45 |
| `p30` | 毎時 :00/:30 |
| `p60` | 毎時 :00 |

60の約数でない値（例：`p7`）は従来の millis() 相対動作になります。

1分ごとに DS3231 から時刻を再取得し、長期ドリフトを自動補正します。

### 【新コマンド】

| コマンド | 説明 |
|----------|------|
| `TYYYYMMDDHHmmss` | RTC 時刻設定（例：`T20260311143000`） |
| `u1` | RTCアライン有効（既定） |
| `u0` | RTCアライン無効（millis() 相対に切替） |

### 【`q` に RTC 時刻表示を追加】

```
[RTC] 2026/03/11 14:23:45  Align=ON(RTC)
[CFG] EEPROM_VER=5 SRC=DIGITAL(LOCK) MIN=500 MAX=3900 PER(min)=15 ...
```

### 【EEPROM バージョン更新（ver=5）】

v2.01（ver=4）からの更新時、既存設定を引き継いで自動マイグレーションします。

### 【v2.01 の全機能を継承】
- 送信直後ガード（postTxIgnore）
- 周期ID catch-up 対策
- 抑止中も A0 BUSY 観測継続
- 周期ID 静寂ガード（`k####`）
- DFPlayer フェイルセーフ（`d####`）
- TM BUSY 極性切替（`g0/g1`）
- AUTO 判定（`m2`）

## ■ 初回セットアップ手順（v2.10）

```
1. Ver.5 基板に v2.10 を書き込む
2. J5 コネクタに DS3231 モジュールを接続
3. シリアルモニタ（115200bps）を開く
4. 起動ログで [RTC] DS3231 found. を確認
5. T20260311143000 → 現在時刻を設定（14桁）
6. p15（または p10/p30）で周期を設定
7. q で確認 → Align=ON(RTC) が出れば正時アライン動作中
8. TM BUSY 極性を確認（g0/g1）
9. テストSW（D2）1クリック → Track 1 再生確認
```

## ■ v2.01 からのアップグレード

### EEPROM の互換性

v2.10 の EEPROM レイアウト（ver=5）は v2.01（ver=4）から **`rtcAlignOn` フィールドを追加**しています。  
書き込み後の初回起動時に自動マイグレーションが行われ、既存設定はすべて引き継がれます。

- `F`（初期化）は**不要**です。
- 起動ログに `[EEPROM] Settings Loaded.` が出れば正常です。

### コマンドの変更

v2.01 から v2.10 への**コマンド変更はありません**。新コマンド（`T` / `u0/u1`）が追加されたのみです。

## ■ DS3231 について

DS3231 は高精度 RTC（リアルタイムクロック）チップです。コイン電池（CR2032）でバックアップされ、電源断中も時刻を保持し続けます。**時刻の自動取得機能はない**ため、初回および電池交換後に `T` コマンドで時刻を設定する必要があります。

AT24C32（モジュール上の外部 EEPROM）は本バージョンでは未使用です。

## ■ LED 表示の意味

| LED | ピン | 点灯条件 |
|-----|------|---------|
| ModBusy LED | D4 | BUSY 受信中（readBusy()=true） |
| 抑止 LED | D6 | 抑止中（長話/バースト/POST-TX） |
| A0検知 LED | D7 | A0 BUSY 検知中 |
| DFP BUSYミラー | D3 | DFPlayer 再生中（HIGH） |

## ■ フェイルセーフ（DFPlayer BUSY 異常）

DFPlayer BUSY が戻らない場合、**d#### ms 経過後に強制 PTT OFF**。

- 既定：d20000（20秒）
- d0：無効

---

## ■ トラブルシューティング

**● IDが出ない**
- 停止中（x）→ `R`（大文字）で復帰
- 長話（b3900超）→ 抑止中
- D6 LED 点灯中（抑止）では動作しない

**● 周期IDが正時にずれる**
- `q` で `Align=ON(RTC)` が出ているか確認
- DS3231 未接続の場合 `Align=OFF(millis)` になる
- `T` コマンドで時刻を再設定

**● DS3231 が認識されない**
- J5 コネクタの SDA/SCL/VCC/GND の配線を確認
- `q` で `N/A(no RTC)` が出る場合は未接続または故障

**● STOP 後に復帰できない**
- `R`（大文字）を入力。`r`（小文字）では復帰しない。

**● BUSY判定が逆**
- g0/g1 の設定確認（`q` で現在の極性を表示）

## ■ 配線メモ（v2.10 / Ver.5 基板）

```
DFPlayer TX → D13（Arduino RX）
DFPlayer RX ← D12（Arduino TX）
DFPlayer BUSY（LOW=再生中）→ D10
D10 BUSYミラー（反転）→ D3
TM BUSY → D11（g0/g1 で極性指定）
PTT → D5（HIGH=送信）
ModBusy LED → D4
抑止 LED → D6
A0検知 LED → D7
テストSW → D2（INPUT_PULLUP）
アナログBUSY → A0
DS3231 SDA → A4
DS3231 SCL → A5
```

---

## ■ 重要仕様（抜粋）

**【RESUME コマンド】**  
STOP 中の復帰は **`R`（大文字）** です。`r`（小文字）は送信後抑止時間設定コマンドです。

**【周期ID 正時アライン（p## / u0/u1）】**  
DS3231 接続かつ `p##` が60の約数のとき、毎正時基準で等間隔送出。  
1分ごとにドリフト補正。`q` で `Align=ON(RTC)` / `Align=OFF(millis)` を確認可能。

**【周期ID 静寂ガード（k####）】**  
BUSY OFF → k#### ms 静寂で周期ID 許可。BUSY中・静寂不足・抑止期間中は延期。

**【EEPROM バージョン（CONFIG_VERSION=5）】**  
v2.01（ver=4）からの更新時、自動マイグレーションが働き設定を引き継ぎます。
